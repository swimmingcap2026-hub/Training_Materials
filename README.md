# ASML EUV 曝光機 · 3D 互動教材

單一 HTML 檔案的離線 3D 教材，用來說明 ASML EUV（NXE / EXE 系列）極紫外光曝光機的
**結構**與**曝光製程**。開啟檔案即可使用，**不需要網路、不需要安裝任何東西**。

📄 **[`ASML_EUV_3D_Training.html`](ASML_EUV_3D_Training.html)**（約 780 KB，雙擊用瀏覽器開啟即可）

---

## 功能

| 功能 | 說明 |
|---|---|
| **3D 互動模型** | 程序化建構的整機模型：CO₂ 驅動雷射 → 光源腔 → 照明系統 → 光罩台 → 投影光學箱 → 晶圓台 → 物料傳輸 |
| **剖面圖** | 可選 X / Y / Z 切割軸並拖曳切面位置，即時剖開真空腔看內部光學排列（地板與光路不會被切掉） |
| **爆炸圖** | 0–100% 連續調整分離量，各模組沿設計方向散開，適合說明組裝關係 |
| **部件解說** | **51 個部件**，每個都有規格表、功能說明、在製程中的角色與重點觀念 |
| **製程流程演示** | **14 段**流程，從晶圓進料、錫液滴、電漿、收集鏡、照明、光罩、六面鏡投影到掃描曝光，可自動播放 |
| **EUV 光路動畫** | 依製程步驟逐段點亮光路，光子粒子沿實際折射路徑流動 |
| **標籤 / 聚焦 / 線框** | 全部件標籤、只顯示相關部件、線框模式、外殼透明度調整 |
| **機型規格比較** | NXE:3400C / NXE:3600D / NXE:3800E / EXE:5000 (High-NA) 對照表 |
| **隨堂測驗** | 10 題觀念題，答題後即時顯示解析 |
| **PNG 截圖輸出** | 一鍵把目前視角輸出成圖片，方便放進簡報 |

## 操作

- **左鍵拖曳**旋轉 · **右鍵／Shift+拖曳**平移 · **滾輪**縮放
- **點擊任何部件**看解說；左側清單可分類瀏覽或搜尋（中／英文皆可）
- 底部時間軸為製程流程，按 ▶ 自動播放
- 快捷鍵：`空白鍵` 播放/暫停 · `←` `→` 上/下一步 · `C` 剖面 · `E` 爆炸 · `L` 標籤 ·
  `B` 光路 · `F` 聚焦模式 · `R` 重設 · `1`–`5` 視角預設 · `Esc` 取消選取
- 支援手機／平板（觸控旋轉與雙指縮放，底部分頁切換面板）

## 教材涵蓋範圍

**EUV 光源（LPP）** — CO₂ 驅動雷射 MO-PA、光束傳輸系統、最終聚焦模組、錫液滴產生器與追蹤、
預脈衝／主脈衝、雷射產生電漿、收集鏡、錫捕集與碎屑緩解、中間焦點 IF、氫氣清潔

**照明系統** — 場刻面鏡、瞳刻面鏡、照明光瞳形狀、中繼鏡、REMA 遮蔽刀

**光罩系統** — 反射式光罩（Mo/Si 多層膜 + TaBN 吸收層）、Mask 3D 效應、EUV 護膜、
靜電夾具、磁浮光罩台、光罩傳輸與雙層光罩盒

**投影光學** — 六片非球面反射鏡 M1–M6、NA 0.33、4× 縮小、波前感測與像差主動補償

**晶圓平台** — 靜電吸盤、短行程／長行程、平面馬達磁浮、平衡質量、雙工件台 TWINSCAN

**量測與控制** — 對準、調平／聚焦、劑量控制、載台位置量測

**機構與廠務** — 基座／力／量測三層框架、主動隔振、真空分區抽氣、負載鎖定室、除氣模組

## 技術說明

- 單一檔案、零外部相依：[three.js](https://threejs.org) r160（MIT License）已內嵌於 HTML 中，
  所有 3D 幾何為程序化生成，無任何外部模型、圖片或字型檔。
- 軌道控制器、剖面裁切、爆炸位移、標籤投影與自動取景皆為本檔自行實作。
- 已於 Chromium 實測：桌面（1500–1600 px）與行動裝置（414 px）版面、
  全部 14 段流程、51 個部件選取、鍵盤快捷鍵、剖面／爆炸／截圖功能均正常，無 console 錯誤。
